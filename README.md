## 📌 Overview
**Recatch**는 결제 승인 순간, 사용자가 가진 카드·통신사·멤버십 혜택을 실시간으로 분석하여 **소비자가 놓친 최적의 할인 정보와 바코드를 결제 직후 1초 만에 팝업 알림**으로 챙겨주는 핀테크 서비스입니다.

---

## ✨ Key Features

* ⚡ **1초 실시간 혜택 트리거**  
  결제 승인 내역 수신 즉시 해당 매장에서 적용 가능한 최적의 할인을 자동 분석합니다.
* 🎯 **100% 초개인화 매칭**  
  보유 카드, 전월 실적, 통신사 멤버십 등 내 프로필 기반의 맞춤형 혜택만 정밀 추출합니다.
* 🚀 **Zero-Depth 바코드 팝업**  
  앱 실행 및 복잡한 이동 경로 없이, 알림을 터치하는 즉시 할인 바코드가 전체 화면으로 팝업됩니다.
